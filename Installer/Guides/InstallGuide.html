Install guide

This page opens when setup starts. Extracted package folder:

Installer file:

  1. In Chrome, turn on Developer mode and choose Load unpacked.
  2. From the path above, select the Extension folder. Chrome loads the extension.
  3. The installer detects the ID and displays it above. If it cannot, copy the ID from the Chrome card and enter it in the installer window.
  4. If asked for a Chromium ID, press Enter to skip it. Then reload DA SSL at chrome://extensions.
Do I repeat this every time?
No. Setup is needed once for this Windows account and extension ID. You do not need to reinstall it whenever Chrome restarts.
