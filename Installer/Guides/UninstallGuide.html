Uninstall guide

To remove DA SSL completely, run this file from the extracted package folder:

  1. On the Chrome extensions page, find DA SSL and choose Remove.
  2. Return to the command window and press Enter to remove the helper and its Windows registration.
  3. After it finishes, you can delete the extracted package folder.
This page is a guide. Run Uninstall.cmd to remove the helper. After selecting Remove, return to the Uninstall.cmd window and press Enter; minimize the browser if needed.
